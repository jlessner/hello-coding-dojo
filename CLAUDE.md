# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
mvn test                    # compile and run all tests
mvn test -Dtest=ClassName   # run a single test class
mvn compile                 # compile production code only
```
## Rules
Use the principles of object-orientation und domain driven design. Apply a reasonable separation of concerns. All classes should take over responsibility. Keep the principles of integration operation segregation and single level of abstraction in mind when structuring classes and methods.
